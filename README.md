# Chinamap-miniprogram（途途相册 · 省份打卡）

一个微信小程序：在中国地图上点亮你去过的省份，给每个省份上传一张照片，自动生成一张「旅行足迹海报」。

> 小程序内显示名为 **「途途相册」**；本仓库为源码工程，命名为 `Chinamap-miniprogram`。

---

## ✨ 功能特性

- **省份打卡**：一张中国地图，34 个省级行政区为最小单元；点选省份即在地图上高亮点亮。
- **照片上传**：选图后弹出微信原生**正方形裁剪框**，保存为 1:1 方图；上传后被居中裁方绘制（`object-fit: cover`），长方形照片不会被拉伸变形。
- **旅行海报**：一键生成海报——中国地图 + 已点亮省份的照片 + 去过的地方清单 + 日期；可保存到相册。
- **离岛 / 飞地小图**：海南（三沙市）、台湾（金門/澎湖/連江）等跨海区域，以右下角小图（inset）形式呈现，样式与全国地图南海诸岛一致。
- **隐私合规**：接入微信隐私授权流程（`__usePrivacyCheck__` + `onNeedPrivacyAuthorize`），首次使用相册/摄像头/头像时弹窗授权。
- **两级数据驱动架构**：`country → province` 靠统一抽象切换数据源，扩展新区域只需「加数据 + 加一层逻辑」，不复制工程。

---

## 🧱 技术栈

- 微信小程序原生（WXML / WXSS / JS）
- Canvas 2D 绘制地图与海报
- 地理数据：GeoJSON 经 Douglas-Peucker 简化 + 归一化后预计算为紧凑数组（`utils/geo/*.js`）

## 🚀 本地运行

1. 安装并打开 **微信开发者工具**。
2. 选择「导入项目」，目录指向本仓库根目录 `Chinamap-miniprogram`。
3. AppID：`wxe95b10a89e4381fd`（或使用测试号）。
4. 编译即可在模拟器中预览；点「上传照片」测试需先通过隐私授权弹窗。

> ⚠️ 若改过代码后界面没更新，点「清缓存 → 全部清除 → 重新编译」。

## 🔒 隐私合规（发布必读）

本项目使用了以下隐私接口，已在微信公众平台「用户隐私保护指引」中声明：

| 接口 | 用途 |
|---|---|
| `chooseMedia`（相册 / 摄像头） | 选择或拍摄照片上传到地图 |
| 相册（仅写入） | 保存生成的旅行海报 |
| 微信昵称 / 头像 | 展示在海报右上角 |

后台声明路径：**mp.weixin.qq.com → 设置 → 用户隐私保护指引**。本地 `__privacy__.json` 为同源声明，二者需保持一致。

## 📦 构建注意

- 34 省紧凑数组合计约 0.75MB，主包总计约 1.23MB（< 2MB 上限），**无需分包**。
- `utils/geo.js` 中的 `GEO_SOURCES` 必须用**显式静态 `require`** 映射每个省文件；**不可**使用 `require('./geo/'+id+'.js')` 动态拼接，否则微信打包器无法静态解析、会导致模块漏打、运行时找不到。
